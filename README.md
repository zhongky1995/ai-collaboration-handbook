# AI 协作入门课

一套面向非技术工作者的中文 AI 协作课程。它不教“万能提示词”，而是帮助读者把一个真实工作请求，变成 AI 能参与、自己能核验的交付过程。

在线阅读：<https://zhongky1995.github.io/ai-collaboration-handbook/>

## 三层课程

- **核心入门课 · 16 节**：任务判断、任务定义、材料选择、常见交付、事实核查与 Workflow；
- **进阶工程课 · 8 节**：Agent Loop、工具权限、Harness、Eval 与能力资产；
- **按需资料**：5 篇参考、2 个案例实验室和 1 份可选工作簿。

首页五个核心模块和学习路线中的每一节都可以直接点击。练习用于验证理解，不是继续阅读的门槛。

## 本地阅读

直接打开 `index.html` 即可阅读。修改 `content/` 后运行：

```bash
npm run build
npm run check
```

推送到 `main` 后，GitHub Pages 会自动更新公开网页。

## 内容边界

案例会明确标注为真实、匿名、综合或教学演示。事实、高风险判断和不可逆行动始终需要人负责；本课程不构成法律、医疗、财务或组织政策建议。
