## 深入理解与原有知识

## 这一讲解决什么问题

AIGC 输出看起来直观，反而容易让人放松检查。文本错误可以通过读句子发现，视觉错误有时更隐蔽：人物手部异常、品牌相似、图像暗示不当、场景不符合事实、肖像和版权风险不清。

这一讲训练的是：AIGC 结果能不能用，应该怎么检查。

## AIGC 的四类风险

| 风险 | 常见表现 | 处理方式 |
|---|---|---|
| 事实风险 | 图片呈现了不真实的产品、场景、流程或数据 | 不用于事实证明，只作示意 |
| 版权风险 | 风格过度接近某个在世创作者、作品或商业素材 | 避免指定受保护风格，保留生成记录 |
| 肖像风险 | 像真实人物、员工、客户或公众人物 | 不生成真实人物身份，不冒充照片 |
| 品牌风险 | 出现疑似 logo、商标、品牌色或错误包装 | 删除或重生成，正式发布前人工确认 |

## 哪些场景可以直接试

适合低风险尝试：

- 内部头脑风暴。
- 课程文章配图。
- PPT 视觉草图。
- 活动视觉方向探索。
- 视频分镜草稿。
- 个人学习作品。

这些场景可以把 AIGC 当作候选和草图，但仍要检查是否会误导读者。

## 哪些场景必须谨慎

必须谨慎处理：

- 客户对外海报。
- 品牌官网主视觉。
- 商业广告。
- 涉及真实人物的图片。
- 产品功能截图。
- 医疗、法律、金融、教育评价等严肃场景。

这些场景不能只靠“看起来不错”。需要更严格的版权、事实、品牌和责任确认。

## 发布前检查清单

| 检查项 | 问题 | 不合格时如何处理 |
|---|---|---|
| 使用场景 | 这张图是内部草图、课程配图，还是对外发布物 | 对外场景提高复核等级 |
| 事实表达 | 图中是否暗示了真实产品、数据、人物或流程 | 改成示意图，或补充说明 |
| 文字 | 是否有乱码、错误文字或不可控标识 | 删除文字，后期手动排版 |
| 品牌 | 是否出现 logo、商标、品牌名或相似视觉元素 | 重生成或人工清理 |
| 人物 | 是否像真实人物，是否涉及肖像权 | 改成非特定人物或抽象角色 |
| 风格 | 是否过度接近某个创作者、作品或商业 IP | 改成通用风格描述 |
| 可访问性 | 画面重点是否清楚，是否过度复杂 | 简化构图、提高对比 |
| 交付格式 | 尺寸、比例、清晰度是否适合使用位置 | 重设比例或重新生成 |

## AIGC 验收提示词

可以让 AI 帮你做初步检查，但最终判断仍然由人负责。

```text
请帮我检查这张 AIGC 图片是否适合用于【使用场景】。

请从以下维度逐项判断：
1. 是否服务表达目标。
2. 是否有事实误导。
3. 是否有文字、logo、品牌或版权风险。
4. 是否有人物肖像风险。
5. 是否需要人工修改。

输出表格：
检查项 / 发现的问题 / 风险等级 / 修改建议。
```

## 常见失败

1. 图很漂亮，但和文章要讲的问题无关。
2. 图中出现乱码文字，却被忽略。
3. 生成了类似真实品牌或 IP 的元素。
4. 把示意图当作事实证据使用。
5. 没有保留生成 prompt，后续无法复盘。

## 练习

找一张 AIGC 图片，按发布前检查清单做一次验收。

输出：

1. 使用场景。
2. 原始 prompt。
3. 图片可用点。
4. 图片风险点。
5. 是否能发布。
6. 如果不能发布，应该如何修改。

## 验收标准

完成这一讲后，你应该能做到：

- 知道 AIGC 图片需要经过人工验收后再进入使用。
- 能识别事实、版权、肖像和品牌风险。
- 能为不同使用场景设置不同复核强度。
- 能保留 prompt、生成结果和人工验收记录。
