## 深入理解与原有知识

## 这一讲解决什么问题

很多人做 AIGC 时会遇到同一个问题：同一句 prompt 有时很好，有时很怪；越加形容词，结果越不稳定。

原因通常不是“审美不够”，而是你还没有和 AI 约定哪些信息必须稳定、哪些信息可以自由发挥。

这一讲训练的是：如何把 AIGC 从“抽卡”变成“有方向的创作流程”。

这里的“可控”不是把 AI 当成完全听话的作图工具，而是把协作边界说清楚：人负责用途、标准、取舍和发布责任；AI 负责生成候选、提供变化方向和帮助迭代。

## 技巧一：先决定这次要控制哪个变量

一张图至少有五个变量：主体、环境、构图、风格、限制。一次修改不要同时改太多。

| 你想控制什么 | prompt 里应该写什么 | 不要怎么写 |
|---|---|---|
| 主体 | 一个业务同事在桌前整理视觉 brief | 很有 AI 感的人 |
| 环境 | 干净的办公桌、电脑、便利贴、候选图缩略图 | 高级、未来、科技 |
| 构图 | 16:9 横版，左到右流程，四个视觉区域 | 画面丰富一点 |
| 风格 | 半扁平 editorial illustration，清爽专业 | 好看、精致、有质感 |
| 限制 | 不要可读文字、logo、品牌名、水印 | 不要太乱 |

如果你一轮只改构图，就不要同时改风格；如果你一轮只改颜色，就不要顺手换主体。

## 技巧二：少用抽象形容词，多写可见细节

弱表达：

```text
生成一张高级、有质感、有未来感的 AI 学习图片。
```

问题是：“高级”“有质感”“未来感”都很抽象。模型会用常见套路补全，比如蓝紫色光效、机器人、发光大脑。

更稳的表达：

```text
16:9 横版插画。一个业务同事在干净办公桌前整理 AI 学习计划，桌面有笔记本、电脑、三张候选图片缩略图和勾选标记。整体是白色和浅灰背景，少量绿色强调色，画面清爽、克制、适合企业内部学习材料。不要机器人、不要发光大脑、不要可读文字。
```

这里的关键不是 prompt 更长，而是每句话都能在画面里被看见。

## 技巧三：把参考素材的角色说清楚

如果你上传参考图、视频或音频，不要只把文件丢进去。要告诉 AI 每个素材负责什么。

| 参考素材 | 适合承担的角色 | 示例说法 |
|---|---|---|
| 图片 | 主体、构图、颜色、材质、风格 | 图 1 作为构图参考，图 2 作为颜色和插画风格参考 |
| 视频 | 镜头运动、节奏、动作、转场 | 视频 1 只参考镜头推进和节奏，不参考人物和场景 |
| 音频 | 情绪、节奏、氛围、转场力度 | 音频 1 作为背景节奏参考，画面切换跟随鼓点 |
| 草图 | 结构、布局、模块关系 | 草图只参考左右布局，不参考手绘风格 |

一个常见错误是：上传三张图，然后只说“参考这些图生成”。这样 AI 不知道该参考主体、颜色、构图，还是风格。

更好的写法：

```text
图 1 只作为版式结构参考：保留左侧标题区和右侧流程区。
图 2 只作为色彩参考：使用白色、浅灰和绿色强调色。
图 3 只作为图标风格参考：使用简洁线性图标，不要复制图中具体内容。
```

## 技巧四：先生成候选方向，再做小步迭代

不要一上来就把 AI 当成完整设计负责人，要求它直接给出可发布成品。可以先要求它给多个方向：

```text
请基于同一个视觉 brief，生成 4 个不同方向：
1. 更适合课程文章配图。
2. 更适合 PPT 封面。
3. 更适合活动宣传图。
4. 更适合流程说明图。

四个方向都不要可读文字，不要 logo，不要科幻机器人。
```

拿到候选后，不要说“再高级一点”。用更具体的反馈：

| 反馈目标 | 更好的说法 |
|---|---|
| 背景太乱 | 简化背景，只保留桌面、电脑和候选图缩略图 |
| 颜色太花 | 保留白色和浅灰，强调色只用绿色 |
| 人物抢戏 | 缩小人物比例，把重点放在工作流和候选图 |
| 视觉不够流程化 | 增加从左到右的方向感，用箭头或空间关系表达流程 |
| 太像科幻海报 | 去掉发光元素，改成真实办公场景和知识工作氛围 |

## 技巧五：图像里的文字要谨慎

很多图像模型已经能生成短文字，但稳定性仍然取决于工具、语言、字数和版式复杂度。

入门阶段可以按这个规则处理：

- 标题、正文、表格、复杂标签：后期在 PPT、Figma、Canva 或设计工具里加。
- 图片里必须出现的短文字：尽量控制在一个短词或一句极短标题。
- 重要品牌名、产品名、人名：不要让模型自由生成，最好后期手动排版。
- 如果生成图里出现乱码：不要修修补补，直接要求“不要任何可读文字”重新生成。

更稳的 prompt：

```text
画面中不要出现任何可读文字、字母、数字、logo 或水印。请用图标、缩略图、勾选标记和空间关系表达流程。
```

## 技巧六：图生视频时，图片负责画面，prompt 负责运动

图生视频和文生图不一样。

如果你已经给了一张起始图片，图片通常已经定义了主体、构图、光线和风格。此时 prompt 不要重复描述图片里已有的一切，而要描述：

- 主体怎么动。
- 镜头怎么动。
- 环境有没有轻微变化。
- 动作持续多久。
- 是否需要保持一个连续镜头。

弱表达：

```text
把这张 AI 学习配图变成一个很酷的视频。
```

更稳的表达：

```text
8 秒，一镜到底。镜头从左侧任务说明卡缓慢推进到右侧最终素材，候选图缩略图轻微浮起，勾选标记依次亮起。整体运动克制、平稳，不要快速切镜，不要改变人物和桌面布局，不要新增文字。
```

## 技巧七：用时间线写短视频

如果你要生成短视频，不要写成长故事。把它拆成时间段。

```text
0-3 秒：镜头缓慢推近桌面，视觉 brief 卡片进入画面。
3-6 秒：屏幕上出现 3 张候选图缩略图，依次被高亮。
6-8 秒：一个勾选标记落在最终图上，镜头停住。

要求：一镜到底，动作平稳，画面保持清爽，不出现可读文字。
```

这个写法比“做一个 AI 创作流程视频”更可控，因为它告诉模型每个时间段发生什么。

## 技巧八：建立自己的候选评审表

AIGC 创作不要只凭第一眼喜欢。可以用一个简单评审表。

| 候选 | 表达目标 | 构图 | 风格 | 风险 | 处理决定 |
|---|---|---|---|---|---|
| A | 是否说清主题 | 是否适合版面 | 是否符合场景 | 是否有文字、品牌、肖像风险 | 保留/重生成/后期修改 |
| B |  |  |  |  |  |
| C |  |  |  |  |  |

如果连续三次都失败，不要继续换形容词。回到 brief，检查是不是使用场景、主体、构图或限制没有说清楚。

## 可复用 prompt 模板

### 图片生成模板

```text
用途：

画面主体：

发生的事情：

场景和背景：

构图和比例：

风格和媒介：

色彩和光线：

必须包含：

必须避免：

验收标准：
```

### 参考素材模板

```text
图 1 作为【构图/主体/风格/颜色】参考：

图 2 作为【构图/主体/风格/颜色】参考：

请不要复制参考图中的具体文字、logo 或人物身份。
最终画面需要服务的用途：
```

### 图生视频模板

```text
基于这张图生成【时长】秒视频。

主体动作：
镜头运动：
环境运动：
时间线：
必须保持不变：
必须避免：
```

## 练习

选择一个你自己的视觉任务，连续做三轮：

1. 第一轮只生成 3 个方向，不追求可发布成品。
2. 第二轮只选一个方向，修改构图或色彩中的一个变量。
3. 第三轮做发布前检查，决定能否使用。

输出一份候选评审表。

## 验收标准

完成这一讲后，你应该能做到：

- 不靠堆形容词解决 AIGC 不稳定。
- 能说明每个参考素材的作用。
- 能用小步迭代改进生成结果。
- 能区分图片 prompt 和视频 prompt 的写法。
- 能用评审表判断候选图是否值得继续修改。
