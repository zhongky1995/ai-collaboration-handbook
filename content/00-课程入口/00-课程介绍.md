# 课程介绍：从理解 AI 到读懂 Agent 与 Harness

这套知识库面向会使用通用 AI、但希望建立系统理解的业务型知识工作者。你不需要编程，也不需要先记住全部术语。

## 你会理解什么

你会沿 Prompt → Context → Workflow → Agent Loop → Harness → Skill / AgentOS 逐层理解：为什么随口提问不稳定，什么时候需要流程，Agent 为什么需要状态与停止条件，Harness 又怎样补上权限、验证、轨迹和恢复。

主线以阅读为主。每个阶段都配有案例、对照和可选练习，但没有必须提交的作品。

## 课程不替你做什么

AI 输出是候选，不是已核验事实。课程的结构检查不能替代领域判断、数据政策、版权核验和发布审批。任何不可逆或高风险动作都需要人工门。
