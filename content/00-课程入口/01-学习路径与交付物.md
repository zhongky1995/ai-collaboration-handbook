# 学习路径：六个知识阶段与可选练习

| 阶段 | 主要理解 | 阅读后可以尝试（可选） |
|---|---|---|
| Prompt | 模型为什么只能生成候选答案，任务为什么需要目标、输入、输出和验收 | 写一张任务卡 |
| Context | 上下文窗口、材料选择、来源、版本和模板的关系 | 选择一组材料 |
| Workflow | 步骤、状态、检查点、人工门和异常分支 | 画一条工作流 |
| Agent Loop | 观察、行动、工具结果、状态更新、停止和恢复 | 运行一个固定情境模拟 |
| Harness | 权限、预算、Trace、Eval 与异常恢复怎样共同约束运行 | 配置一个最小 Harness |
| Skill / AgentOS | 方法怎样被封装、交接、登记、版本化和持续改进 | 整理一张能力资产卡 |

你可以顺序阅读，也可以从最关心的阶段开始。案例、互动和作品模板都用于帮助理解，不承担解锁下一章的作用。
