# AI 协作知识库

这是一套以阅读和理解为主的 AI 入门知识库，面向不需要编程、希望系统理解 AI 协作方式的读者。

## 最轻松的开始方式

打开 [知识库首页](../index.html)，点击 **从第一篇开始阅读**。你会先理解 AI 到底改变了什么，再逐步读到上下文、Workflow、Agent、Harness 和能力资产。

不需要先完成任务，也没有必须打卡的作业。案例、互动和作品模板都只是帮助理解的可选工具。

## 一条贯穿全程的知识路线

`Prompt → Template / Context → Workflow → Agent Loop → Harness → Skill / AgentOS`

这条路线解释 Prompt 怎样逐步发展为更稳定的系统：从目标与验收，到材料与版本、状态与人工门、动态选择与恢复、权限/Trace/Eval，再到 handoff、registry 和版本反馈。Agent 与 Harness 不是末章选修，而是前面知识自然发展的结果。

## 四种使用方式

- **学习首页**：开始阅读或继续上次读到的位置；
- **课程目录**：按六个阶段浏览 28 篇主线内容；
- **知识检索**：快速查模型、Embedding、RAG、上下文、工具与风险；
- **案例练习**：读案例，或在愿意时做一次低压力练习。

所有核心内容可离线打开。事实与高风险判断始终由人负责；框架、仓库与实践观点会按来源性质标记。练习记录与阅读路径相互独立。
