# 可选工作簿：从六格任务卡到方法沉淀

这份工作簿服务于 16 节核心课。它不是作业清单，也不决定你能不能继续阅读。你只需要复制当前任务用得上的一张卡。

[打开可保存并获得结构反馈的六格任务卡](#/learn/first-task)

## 01 · 先判断 AI 参与哪一段

```text
真实任务：

适合 AI 参与：
- 材料整理：
- 候选生成：
- 格式转换：

必须由人复核：
- 关键事实：
- 业务取舍：

不应直接委托：
- 高风险判断：
- 不可逆行动：

理由：
```

自检：你是否写清了 AI 参与的具体环节，而不是只写“这个任务可以/不可以用 AI”？

## 02 · 六格任务卡

```text
任务名称：

1. 用途与读者
- 谁会使用结果：
- 要用它做什么决定或行动：

2. 可用材料
- 材料 / 来源 / 日期或版本 / 用途：

3. 输出形态
- 篇幅：
- 结构：
- 交付形式：

4. 边界
- 不得使用或自行补全：
- 遇到什么情况必须暂停：
- 哪些动作必须先获得人工确认：

5. 验收标准
1.
2.
3.

6. 人类责任
- 谁核验事实：
- 谁做最终取舍：
- 谁批准发布或正式行动：
```

自检：

- 用途里是否有一个真实决定，而不只是“了解一下”；
- 材料是否有范围、版本或时间；
- 边界是否包含明确的禁止项或暂停条件；
- 验收标准能否逐条判断“满足/不满足”；
- 人类责任是否指向具体角色。

## 04 · 研究证据与建议

```text
研究问题：

| 材料中的事实 | 材料位置 | 可以形成的有限推断 | 不能推出什么 |
|---|---|---|---|
|  |  |  |  |

建议：

建议依据：

待确认项：

最终由谁决定：
```

自检：

- 每个关键事实能否回到材料；
- 推断是否被写成了确定事实；
- 建议是否服务于原定决定；
- 未知项是否被保留下来。

## 05 · 事实核查记录

```text
| 待核查说法 | 影响什么决定 | 当前来源 | 核查结果 | 处理方式 | 负责人 |
|---|---|---|---|---|---|
|  |  |  |  | 保留 / 改写 / 删除 / 暂停 |  |
```

优先核查会改变结论、可能造成风险或会被对外发布的说法。事实核查不是给所有句子加链接，而是让关键判断有证据。

自检：材料缺失、来源冲突或核查失败时，流程是否会暂停，而不是悄悄继续？

## 07 · 方法复盘卡

```text
这次任务：
有效做法：
失败或返工：
下次复用前必须满足：
不适用的情况：
保存的模板或示例：
维护人：
版本：
```

不要把一次偶然成功直接写成“最佳实践”。至少在第二次相似任务中验证它是否仍然有效，再决定是否沉淀为个人 Skill。

## 什么时候需要进阶模板

如果固定 Workflow 已经足够，就停在这里。只有任务需要根据中间结果动态选择工具、来源或重试方式，才进入进阶工程课，继续设计 Agent 与 Harness。
