# 可选工作簿：从六格任务卡到方法沉淀

这份工作簿服务于 16 节核心课。它不是作业清单，也不决定你能不能继续阅读。你只需要复制当前任务用得上的一张卡。

[打开可保存并获得结构反馈的六格任务卡](#/learn/first-task)

## 01 · 先判断 AI 参与哪一段

```text
真实任务：

适合 AI 参与：
- 材料整理：
- 候选生成：
- 格式转换：

必须由人复核：
- 关键事实：
- 业务取舍：

不应直接委托：
- 高风险判断：
- 不可逆行动：

理由：
```

自检：你是否写清了 AI 参与的具体环节，而不是只写“这个任务可以/不可以用 AI”？

## 02 · 六格任务卡

```text
任务名称：

1. 用途与读者
- 谁会使用结果：
- 要用它做什么决定或行动：

2. 可用材料
- 材料 / 来源 / 日期或版本 / 用途：

3. 输出形态
- 篇幅：
- 结构：
- 交付形式：

4. 边界
- 不得使用或自行补全：
- 遇到什么情况必须暂停：
- 哪些动作必须先获得人工确认：

5. 验收标准
1.
2.
3.

6. 人类责任
- 谁核验事实：
- 谁做最终取舍：
- 谁批准发布或正式行动：
```

自检：

- 用途里是否有一个真实决定，而不只是“了解一下”；
- 材料是否有范围、版本或时间；
- 边界是否包含明确的禁止项或暂停条件；
- 验收标准能否逐条判断“满足/不满足”；
- 人类责任是否指向具体角色。

```text
|---|---|---|---|---|
|  |  |  |  |  |

| 材料 | 为什么排除 | 何时重新考虑 |
|---|---|---|
|  |  |  |
```

自检：材料多不等于上下文好。当前纳入的每份材料，是否都支持任务卡中的某个决定或验收条件？

## 04 · 研究证据与建议

```text
研究问题：

| 材料中的事实 | 材料位置 | 可以形成的有限推断 | 不能推出什么 |
|---|---|---|---|
|  |  |  |  |

建议：

建议依据：

待确认项：

最终由谁决定：
```

自检：

- 每个关键事实能否回到材料；
- 推断是否被写成了确定事实；
- 建议是否服务于原定决定；
- 未知项是否被保留下来。

## 05 · 事实核查记录

```text
| 待核查说法 | 影响什么决定 | 当前来源 | 核查结果 | 处理方式 | 负责人 |
|---|---|---|---|---|---|
|  |  |  |  | 保留 / 改写 / 删除 / 暂停 |  |
```

优先核查会改变结论、可能造成风险或会被对外发布的说法。事实核查不是给所有句子加链接，而是让关键判断有证据。

```text
|---|---|---|---|---|
| 已接收 |  |  |  |  |
|  |  |  |  |  |
| 待确认 |  |  |  |  |
| 已完成 |  |  |  |  |

不可逆动作前的人工门：
- 位于：

```

自检：材料缺失、来源冲突或核查失败时，流程是否会暂停，而不是悄悄继续？

## 07 · 方法复盘卡

```text
这次任务：
有效做法：
失败或返工：
下次复用前必须满足：
不适用的情况：
保存的模板或示例：
维护人：
版本：
```

不要把一次偶然成功直接写成“最佳实践”。至少在第二次相似任务中验证它是否仍然有效，再决定是否沉淀为个人 Skill。

## 08 · 需求证据卡

准备做新工具或改流程时使用；已有清楚任务时不必重复填写。

```text
谁在什么时刻遇到问题：
最近一次具体经历与材料位置：
现在采用的做法：
已经发生的成本或返工（没有记录就写未知）：
对方表达的愿望或意见：
目前可以支持的有限判断：
还不能确定什么：
下一次需要追问或观察：
准备比较的最小改动：
```

自检：能否区分实际发生的事、对未来的愿望和自己的推断？AI 模拟访谈只用于准备，不填进真实经历栏。参见[用途从哪里来](../02-人机协作基本功/01-把模糊问题变成AI能执行的任务.md)。

## 09 · 问题求助卡

```text
工具与使用环境：
出问题的版本：
复现步骤（从打开开始）：
使用的输入：
期望结果：
实际现象：
报错原文或截图位置（已去掉凭证与无关数据）：
最近做过哪些改动：
已经尝试什么、结果怎样：
必须保留的正常行为：
修改后的复测步骤：
可恢复的上一份版本：
```

自检：别人能否用同一输入复现？修复后是否验证了原问题和需要保留的行为？如果不知道原因，写出未知，不把猜测写成报错结论。

## 10 · 试用与修改记录卡

```text
作品与版本：
试用者与目标使用者的关系：
交给试用者的任务目标：
使用的材料：
实际操作与卡点：
我在哪一步提供了什么帮助：
对方对卡点的解释（与我的推断分开）：
是否完成、留下了什么结果：

优先修改的问题与依据：
修改动作：
复测使用的版本、输入和任务：
原卡点是否消失：
原先正常的行为是否仍可用：
尚未验证的范围：
```

自检：记录的是实际行为，还是一句“挺好用”？有人协助的结果不记为独立完成；没有真人试用时，明确写“待试用”，不让 AI 补造记录。

可以用[资料核查面板选修练习](../03-高频场景实战/07-用AI做资料核查面板.md)串起这三张卡，也可以换成你正在改进的文档模板或工作流程。

## 什么时候需要进阶模板

如果固定 Workflow 已经足够，就停在这里。只有任务需要根据中间结果动态选择工具、来源或重试方式，才进入进阶工程课，继续设计 Agent 与 Harness。
